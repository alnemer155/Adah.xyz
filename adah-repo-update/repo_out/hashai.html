أحدث نماذج جوجل مفتوحة المصدر، متعددة الوسائط، من e2b إلى 31B.

S1-mini

مجاني — Apache 2.0 تنظيف نص صوتي

من Superwhisper. نموذج صغير (0.6B) ينظّف تفريغ الصوت الخام ويحوّله لنص مقروء.

00 قبل ما تبدأ

ثبّت Ollama أولًا — هو البرنامج اللي يشغّل معظم النماذج على جهازك ويديرها.

macOS / Linux 
curl -fsSL https://ollama.com/install.sh | sh
لويندوز، نزّل المثبّت مباشرة من ollama.com. بعد التثبيت، أي أمر "ollama run" ينزّل النموذج تلقائيًا أول مرة.
01 DeepSeek R1

نموذج استدلال مفتوح المصدر من DeepSeek، يفكّر خطوة بخطوة قبل ما يجاوب. متوفر بأحجام من 1.5B إلى 671B، فيه نسخة تناسب أي جهاز. مجاني بالكامل (رخصة MIT)، نص فقط.

1.5b 7b 8b 14b 32b 70b 671b
تحميل وتشغيل (مثال بحجم 8B) 
ollama pull deepseek-r1:8b
ollama run deepseek-r1:8b
الحد الأدنى المقترح: 8 جيجا رام للحجم 8B، وكل ما كبر الحجم احتاج رام وذاكرة GPU أكثر.
02 GPT-OSS

نماذج OpenAI مفتوحة الوزن (رخصة Apache 2.0)، بإصدارين: 20B للاستخدام المحلي السريع، و120B للمهام الأثقل. تدعم استدعاء الأدوات والاستدلال المتدرّج. نص فقط، ومجانية بالكامل.

GPT-OSS 20B 
ollama pull gpt-oss:20b
ollama run gpt-oss:20b
يحتاج تقريبًا 16 جيجا رام.
GPT-OSS 120B 
ollama pull gpt-oss:120b
ollama run gpt-oss:120b
يحتاج تقريبًا 80 جيجا (GPU من فئة H100 أو ما يعادله).
03 Gemma 4

أحدث عائلة نماذج جوجل مفتوحة المصدر، برخصة Apache 2.0 بدون قيود استخدام. متعددة الوسائط (نص وصورة)، وتدعم حتى 256K من نافذة السياق بالأحجام الكبيرة. مجانية بالكامل.

e2b e4b 12b 26b (MoE) 31b
تشغيل بالحجم الافتراضي (e4b) 
ollama pull gemma4
ollama run gemma4
اختيار حجم معيّن 
ollama run gemma4:e2b
ollama run gemma4:12b
ollama run gemma4:26b
ollama run gemma4:31b
e2b و e4b يشتغلون على لابتوب عادي (~7–10 جيجا رام)، بينما 26b و31b يحتاجون GPU بذاكرة 16–24 جيجا.
04 Qwen 3

عائلة نماذج Alibaba مفتوحة المصدر (Apache 2.0)، نص فقط، تدعم 119 لغة، وفيها وضع تفكير (Thinking) تقدر تشغّله أو توقفه حسب الحاجة للسرعة أو الدقة.

0.6b 4b 8b 14b 32b 30b-a3b (MoE) 235b-a22b (MoE)
تشغيل الحجم الافتراضي (8B) 
ollama pull qwen3
ollama run qwen3
التحكم بوضع التفكير 
ollama run qwen3 --think
ollama run qwen3 --no-think
8B يحتاج تقريبًا 6 جيجا ذاكرة GPU، و30B-a3b (MoE) يقارب سرعة 8B بجودة أعلى إذا كان عندك 20 جيجا رام/VRAM.
05 Flux

نموذج توليد صور من نص من Black Forest Labs. نسخة Schnell مجانية بالكامل (Apache 2.0) وأسرع، ونسخة Dev أعلى جودة لكن للاستخدام غير التجاري فقط. ما يشتغل عبر Ollama — تحتاج Python وحزمة diffusers، أو واجهة ComfyUI.

التثبيت 
pip install diffusers torch accelerate
توليد صورة (FLUX.1-schnell) 
from diffusers import FluxPipeline
import torch

pipe = FluxPipeline.from_pretrained(
    "black-forest-labs/FLUX.1-schnell",
    torch_dtype=torch.bfloat16
)
pipe.enable_model_cpu_offload()

image = pipe("وصف الصورة هنا", num_inference_steps=4).images[0]
image.save("output.png")
يحتاج GPU بذاكرة 12 جيجا فأكثر للأداء المريح. لأجهزة أضعف، استخدم نسخ GGUF مضغوطة عبر ComfyUI بدل diffusers.
06 S1-mini

من Superwhisper. نموذج صغير جدًا (0.6B، مبني على Qwen3-0.6B) ما يفرّغ الصوت بنفسه، بل ينظّف نص مفرّغ خام من الحشو والتكرار ويرتب علامات الترقيم — يجي بعد أي نموذج تفريغ صوت مثل Whisper. مجاني (Apache 2.0)، إنجليزي فقط بالإصدار الحالي.

تشغيل عبر vLLM 
pip install vllm
vllm serve superwhisper/s1-mini
فيه نسخة GGUF مضغوطة (~462MB) تشتغل على أي جهاز حتى بدون GPU، عبر llama.cpp أو أي واجهة تدعم GGUF.
07 استدعاء أي نموذج عبر API

بعد ما يشتغل Ollama، أي نموذج نزّلته يصير متاح محليًا على منفذ 11434 — تقدر تستخدمه من أي تطبيق أو سكربت بدل الأمر التفاعلي.

مثال cURL 
curl http://localhost:11434/api/chat -d '{
  "model": "gemma4",
  "messages": [{ "role": "user", "content": "مرحبا" }]
}'
بدّل قيمة "model" باسم أي نموذج ثبّته (مثل deepseek-r1:8b أو gpt-oss:20b أو qwen3).
